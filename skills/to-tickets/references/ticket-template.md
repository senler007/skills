# Ticket template

Use the project's configured language. Keep implementation freedom unless a
decision has already been confirmed by the parent Spec or an authority.

## Parent

Link the source Spec or parent work item. Omit only when there is genuinely no
parent.

## What to build

Describe the narrow end-to-end behavior this Ticket makes work and how a person
or stable public seam can demonstrate it.

## Acceptance criteria

- Write objective completion conditions.
- Include tests at the parent Spec's confirmed seam where applicable.
- Include required durable-document synchronization without copying its content.

## Blocked by

List only published Ticket identifiers that genuinely prevent this Ticket from
starting, or state `None — can start immediately`.

## Notes

Include links or constraints needed for implementation. Avoid brittle file paths,
code snippets, speculative subtasks, and status narration. Omit when empty.
